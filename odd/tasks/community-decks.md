# Community decks (YGOPRODeck → Evolution)
Objective: a "Comunidad" tab in the deck explorer with legal community decks synced by evolution-api from YGOPRODeck.
Branches: assets `feat/card-alternates-map`, api `feat/community-decks`, client `feat/community-decks-tab`. Delivery: ask-on-risk; chained PRs per repo if a slice passes ~400 authored lines. Test runners: assets `node --test`, api `bun test`, client vitest (touched files) + check:svelte + build + check:bundle.

## Specs
- S1 Source: only evolution-api talks to YGOPRODeck (`https://ygoprodeck.com/api/decks/getDecks.php`, `format=<category>&limit=…&offset=…`, 20 per page). Categories → our formats: "Tournament Meta Decks" → newest TCG section of the base lflist; "Tournament Meta Decks (Genesys)" → Genesys; "Edison Format Decks" → "2010.3 Edison". Goat and JTP are out of scope (no Goat ban list in our system; no JTP category upstream). Polite sync: ≤1 request/second, identifying User-Agent, daily.
- S2 Alternates: user asked "como hariamos con nuestros codigos propios para las erratas edison?". A deck card whose passcode the format list does not allow is replaced by an alternate id whose cdb `alias` is that passcode and which the list allows (e.g. Armory Arm 29071332 → 910003009, Necrovalley 47355498 → 910003011, Quickdraw Synchron 20932152 → 910003005, Brionac 50321796 → 511002993, Goyo Guardian 7391448 → 511002994); otherwise the deck is not legal. evolution-assets publishes the original → alternates map as `cdb/alternates.json`, generated by a script from every cdb's `datas.alias`, with a test that fails when it is stale.
- S3 Validation: after S2, every card allowed by the format's list, copy limits respected, main 40–60, extra ≤15, side ≤15. Illegal decks are never stored or shown.
- S4 Quality: tournament categories pass as is; Edison decks need a complete legal list and a minimum of views (configurable). Duplicates (same sorted main+extra+side) are stored once.
- S5 Storage + API: table `community_decks` (source, source id, url, author, name, format label, cover card, main/extra/side, views, source updated_at, synced_at); upsert per sync, decks gone upstream are removed. Public endpoint `GET /api/v1/community-decks?format=&q=&page=&pageSize=` → `{ items: [{ id, name, author, format, source: "ygoprodeck", sourceUrl, cover, main, extra, side, views, updatedAt }], page, pageSize, total }` and `GET /api/v1/community-decks/formats` → `[{ format, count }]`. Worker behind an env flag like the event-run worker.
- S6 Client: user approved "[Mis mazos] [Plantillas] [Comunidad]" — a "Comunidad"/"Community" tab in the deck explorer with format chips (from `/formats`), search, paging, cards with cover (`cover`), name, author and a "Ver en YGOPRODeck" link; loading opens the deck in the editor with its format.
- S7 Credit: each deck shows its author and links to its YGOPRODeck page. Before enabling in production, YGOPRODeck is told about the use (user decision).
